### 1. Адрес переменной
```cpp
int a{ 5 };
int* b{ &a }; // int* b = &a;
std::cout << b;
std::cout << std::endl;
```

<details>
<summary>Ответ:</summary>

`int* b{ &a }` сохраняет в `b` адрес переменной `a`.
Далее печатается *адрес*, сохраненный в `b`.
Не значение по адресу из `b` (записали бы как `*b`), а адрес в `b`.
</details>

<details>
<summary>Какой тип у переменной <code>b</code>?</summary>

Синтаксис определения переменных состоит из:
1. типа;
2. имеми переменной;
3. необязательно, инициализации.

`int* b{ &a };` — здесь:
1. `int*` — это тип;
2. `b` — это имя переменной;
3. `{ &a }` — это инициализация.

**У `b` тип не `int`, а `int*`!**
</details>

<details>
<summary>Какой тип у выражения <code>&a</code>?</summary>

`&` — это оператор, получающий *адрес переменной*.
`&` применяется **не на значение `a`, а на саму переменную `a`**.

Тип `&a` — это `int*`.
Этот тип хранит во время компиляции информацию о том,
что **получаемый адрес является именно адресом переменной типа `int`, 
а не какого-то другого типа**.

> `&` способен дать адрес *любого объекта*, но об этом в 3-ей лабе.
</details>

### 2. Адрес неинициализированной переменной.

Допустимо ли подобное?

```cpp
int a;
int* b{ &a };
std::cout << b;
std::cout << std::endl;
```

<details>
<summary>Ответ:</summary>

Можно брать адрес неинициализированной переменной.
Напечатается как обычный адрес.

Недопустимо было бы *считывать по* этому адресу.
</details>

### 3. Оператор dereference (на запись)
```cpp
int a { 1 };
int* b{ &a };
*b = 2;
std::cout << a;
std::cout << std::endl;
```

<details>
<summary>Ответ:</summary>

В `b` был сохранен адрес переменной `a`.

На строчке `*b = 2`, `*b` позволяет сослатся на переменную, 
находящуюся по адресу из `b`, то есть на `a`.

`*b = 2` -> `a = 2` вписывает `2` в `a`.
</details>

### 4. Число как адрес

Допустимо ли подобное?

```cpp
int* b{ 32 };
std::cout << *b;
std::cout << std::endl;
```

<details>
<summary>Ответ:</summary>

Нет. Адрес невозможно задать так напрямую, его необходимо получать используя
оператор `&` на что-то с чем связан адрес (например, переменную).
</details>

### 5. Оператор dereference (на чтение)
```cpp
int a{ 5 };
int b{ *(&a) };
std::cout << b;
std::cout << std::endl;
```

<details>
<summary>Правильный ответ:</summary>

Вычисление выражения `*(&a)`:
- `&a` переходит в адрес переменной `a` (скажем, 32).
- `*32` переходит по адресу, позволяя обращатся к переменной `a`.
- ссылка на `a` в качестве выражения дает значение переменной `a`, 5.

`*(&a)` -> `*32` -> `a` -> `5`
</details>

### 6. Печать сложного выражения
```cpp
int a{ 5 };
int* b{ &a };
std::cout << (*b) + 7;
std::cout << std::endl;
```

<details>
<summary>Правильный ответ:</summary>

`(*b) + 7` это выражение. Вычисляется по частям:
- `(*b)` означает переход по адресу из `b` и восприятие этого как переменной `a`.
- `(*b) + 7` -> `a + 7` - `a` заменяется на значение из `a`, потому что используется в качестве выражения.
- `5 + 7` -> `12`.
</details>

### 9. Зависимость адреса от значения

Будет ли в `b` и в `c` тот же адрес?
```cpp
int a = 5;
int* b = &a;
a = 6;
int* c = &a;
```

<details>
<summary>Правильный ответ:</summary>

Будет тот же адрес.

Переменные *никогда не меняют свой адрес*.
`a = 6` впишет 6 в уже имеющуюся ячейку памяти.
Это не перенаправляет `a` в другую ячейку.

`&a` берет адрес *ячейки* `a`, а не значения в ней.
Он всегда будет давать тот же адрес, вне зависимости от того, 
какое значение сохранили в `a`.
</details>


### 10. Это та же память!
```cpp
int a = 5;
int* ap = &a;

*ap = 6;
std::cout << a;
std::cout << std::endl;

a = 7;
std::cout << *ap;
std::cout << std::endl;
```

<details>
<summary>Ответ:</summary>

Запись и чтение всегда происходит по тому же адресу.
`ap` содержит адрес переменной `a`.
Запись в или чтение из `*ap` эквивалентно работе с `a` напрямую.
</details>

### 11. Инициализация через указатель

```cpp
int a;
int* b = &a;
*b = 5;
std::cout << a;
std::cout << std::endl;
```

<details>
<summary>Ответ:</summary>

Переменную можно *инициализировать* через указатель. 
Подобное допустимо.
</details>

### 12. Перезапись указателя
```cpp
int a = 5;

int* p = &a;
*p = 6;

int b = 7;

p = &b;
*p = 8;

std::cout << a;
std::cout << std::endl;

std::cout << b;
std::cout << std::endl;
```

<details>
<summary>Ответ:</summary>

На строчке `p = &b` перезаписывается сам *адрес* из `p` на адрес другой переменной (`b`).

`*p = 8` впишет 8 уже в `b`.

</details>

### 13. Двойной указатель
```cpp
int a = 5;
int b = 6;
int* p = &a;
int** pp = &p;
**pp = 7;
        
*pp = &b;
**pp = 8;

std::cout << a;
std::cout << std::endl;

std::cout << b;
std::cout << std::endl;
```

<details>
<summary>Ответ</summary>
 
```cpp
int a = 5; // скажем, адрес = 32
int b = 6; // скажем, адрес = 36
int* p = &a; // адрес p = 40, адрес в p = 32
int** pp = &p; // адрес в pp = 40
**pp = 7; // *(*pp) --> *(40) --> *(p) --> *32 --> a
         // то есть a = 7
*pp = &b; // адрес в p = 36
**pp = 8; // *(*pp) --> *(40) --> *(p) --> *36 --> b
         // то есть b = 8

std::cout << a;
std::cout << std::endl;

std::cout << b;
std::cout << std::endl;
```
</details>

### 14. auto из адреса

```cpp
int value{ 5 };
auto p{ &value };
*p = 8;
std::cout << value << std::endl;
```

<details>
<summary>Ответ</summary>

У `&value` тип `int*`, поэтому у `p` тоже тип `int*`.
Печатает `8`: запись через указатель с выведенным типом изменяет `value`.
</details>

### 15. auto из указателя и его значения

```cpp
int value{ 5 };
int* p{ &value };
auto copiedPointer{ p };
auto copiedValue{ *p };
*copiedPointer = 8;
std::cout << value << std::endl;
std::cout << copiedValue << std::endl;
```

<details>
<summary>Ответ</summary>

У `p` тип `int*`, а у `*p` — `int`.
Поэтому `copiedPointer` указывает на ту же переменную, а `copiedValue` — отдельная копия целого числа.
Печатает `8` и `5`.
</details>

### 16. auto из адреса указателя

```cpp
int value{ 5 };
int* p{ &value };
auto pp{ &p };
**pp = 9;
std::cout << value << std::endl;
```

<details>
<summary>Ответ</summary>

У `&p` тип `int**`, поэтому у `pp` тип `int**`.
`*pp` обращается к `p`, а `**pp` — к `value`.
Печатает `9`.
</details>

### 17. Размеры указателей
```cpp
int a = 7;
int* pa = &a;
void* voidp = pa;

uint8_t c = 9;
uint8_t* pc = &c;

std::cout << sizeof(pa);
std::cout << std::endl;

std::cout << sizeof(voidp);
std::cout << std::endl;

std::cout << sizeof(pc);
std::cout << std::endl;
```

<details>
<summary>Ответ</summary>

Размер указателя любого типа тот же, потому что это лишь адрес памяти.

На 64-битных системах размер любого указателя 64 бита (скорее всего вы на 64-битной).
</details>

### 18. Размер указателя и переменной

```cpp
int a = 7;
int* ap = &a;

std::cout << sizeof(a);
std::cout << std::endl;

std::cout << sizeof(ap);
std::cout << std::endl;

std::cout << sizeof(*ap);
std::cout << std::endl;
```


<details>
<summary>Ответ</summary>

`sizeof(a)` это то же, что и `sizeof(int)`, 4.

`sizeof(ap)` это то же, что и `sizeof(int*)`, 8.

`sizeof(*ap)` не вычисляет выражение `*ap`, а лишь смотрит, какой тип у результата был бы.
Чтение из `*ap` дало бы `int`, поэтому считается `sizeof(int)`, 4.
</details>

### 19. Указатель на самого себя
```cpp
void* p = nullptr;
p = static_cast<void*>(&p);

std::cout << p;
std::cout << std::endl;

std::cout << &p;
std::cout << std::endl;
```

<details>
<summary>Ответ</summary>

`&p` берет адрес самой переменной `p`.
Тип выражения `&p` — это `void**` (адрес переменной типа `void*`).

`static_cast<void*>(...)` явно преобразует этот `void**` в `void*`,
то есть в тип самой переменной `p`.
Поэтому присваивание `p = static_cast<void*>(&p)` сохраняет
в `p` адрес самой `p` — теперь `p` указывает на саму себя.

Напечатаются два одинаковых адреса: значение в `p` и адрес `&p` совпадают.

Если `static_cast<void*>` тут опустить, он все равно произойдет сам по себе
</details>

### 20. Пустая инициализация указателя
```cpp
int* p{};
std::cout << p << std::endl;
```

<details>
<summary>Ответ</summary>

Пустые фигурные скобки означают, что указатель инициализируется значением по умолчанию.
Для указателей это значение — `nullptr`.
Это то же самое, что написать `int* p{ nullptr };`.

Поэтому напечатается `0` (нулевой адрес).

Это отличается от `int* p;`: там `p` остаётся неинициализированным, и в нём лежат мусорные данные.
В отличие от неинициализированного указателя, читать сам `p` здесь можно (например, печатать его).
Само разыменовывание `p` всё равно недопустимо, так как он ни на что не указывает.
</details>

### 21. Копирование переменной и указателя с похожими именами

```cpp
int x{ 0 };
int* px{ &x };
int y{ x };
int* py{ px };

*px = 1;

std::cout << x << std::endl;
std::cout << y << std::endl;
std::cout << *px << std::endl;
std::cout << *py << std::endl;
```

<details>
<summary>Ответ:</summary>

`int y{ x }` копирует *значение* из `x` — дальше `y` независима от `x`,
поэтому запись через указатель ее не меняет.

`int* py{ px }` копирует *адрес* из `px` — оба указателя смотрят на одну и ту же переменную `x`.

`*px = 1` вписывает `1` в `x`, поэтому напечатается:
- `x` — `1`,
- `y` — `0` (значение скопировано до записи),
- `*px` — `1`,
- `*py` — `1` (указывает туда же, куда и `px`).
</details>


## Задания на проверку типов

Каждый фрагмент независим. Компилируется ли он? Назовите типы обеих сторон последнего присваивания.
Большинство фрагментов намеренно неверны; объясните исправление вместо попытки их выполнить.

### 1. Целое число присваивается указателю

```cpp
int value{ 5 };
int* p{};
p = value;
```

<details>
<summary>Ответ</summary>

Не компилируется.
Справа тип `int`, а слева требуется `int*`.
Чтобы сохранить адрес, используйте `p = &value;`.
</details>

### 2. Указатель присваивается двойному указателю

```cpp
int value{ 5 };
int* p{ &value };
int** pp{};
pp = p;
```

<details>
<summary>Ответ</summary>

Не компилируется.
У `p` тип `int*`, а для `pp` требуется `int**`.
Используйте `pp = &p;`, чтобы указать на переменную-указатель.
</details>

### 3. Указатель присваивается целому числу

```cpp
int value{ 5 };
int* p{ &value };
int result{};
result = p;
```

<details>
<summary>Ответ</summary>

Не компилируется.
`p` — адрес типа `int*`, а не целочисленное значение.
Используйте `result = *p;`, чтобы скопировать значение по указателю.
</details>

### 4. Адрес указателя присваивается указателю

```cpp
int value{ 5 };
int* p{ &value };
int* other{};
other = &p;
```

<details>
<summary>Ответ</summary>

Не компилируется.
У `&p` тип `int**`, а у `other` — `int*`.
Используйте `other = p;`, чтобы скопировать сохранённый адрес, либо объявите `other` как `int**` для хранения `&p`.
</details>

### 5. Адрес целого числа присваивается двойному указателю

```cpp
int value{ 5 };
int** pp{};
pp = &value;
```

<details>
<summary>Ответ</summary>

Не компилируется.
У `&value` тип `int*`, а не `int**`.
Дополнительная `*` в объявлении не означает, что переменная принимает любой адрес.
</details>

### 6. Копирование указателя через двойной указатель

```cpp
int value{ 5 };
int* p{ &value };
int** pp{ &p };
int* other{};
other = *pp;
```

<details>
<summary>Ответ</summary>

Компилируется.
У `*pp` тип `int*`, поэтому присваивание допустимо.
Теперь `other` и `p` указывают на одно целое число.
</details>

### 7. Одно разыменование вместо двух

```cpp
int value{ 5 };
int* p{ &value };
int** pp{ &p };
int result{};
result = *pp;
```

<details>
<summary>Ответ</summary>

Не компилируется.
У `*pp` тип `int*`, а для `result` нужен `int`.
Используйте `result = **pp;`, чтобы прочитать целое число.
</details>

### 8. Запись через два разыменования

```cpp
int value{ 5 };
int* p{ &value };
int** pp{ &p };
**pp = 8;
```

<details>
<summary>Ответ</summary>

Компилируется.
`**pp` обращается к переменной `value` типа `int`.
Присваивание допустимо и записывает в неё `8`.
</details>

### 9. Адрес size_t присваивается указателю на int8_t

```cpp
#include <cstddef>
#include <cstdint>
std::size_t count{ 3 };
std::int8_t* p{};
p = &count;
```

<details>
<summary>Ответ</summary>

Не компилируется.
У `&count` тип `std::size_t*`, а не `std::int8_t*`.
Указатели сохраняют тип объекта; это присваивание не выполняет числовое преобразование.
</details>

### 10. Адрес int8_t присваивается указателю на size_t

```cpp
#include <cstddef>
#include <cstdint>
std::int8_t value{ 3 };
std::size_t* p{};
p = &value;
```

<details>
<summary>Ответ</summary>

Не компилируется.
У `&value` тип `std::int8_t*`, а для `p` требуется `std::size_t*`.
Даже если число помещается в обоих типах, их указатели не становятся совместимыми.
</details>

### 11. Значение int8_t присваивается size_t

```cpp
#include <cstddef>
#include <cstdint>
std::int8_t value{ 3 };
std::size_t count{};
count = value;
```

<details>
<summary>Ответ</summary>

Компилируется.
Это числовое присваивание, поэтому значение преобразуется в `std::size_t`.
В `count` записывается `3`.
Адрес не присваивается и не переинтерпретируется.
</details>

### 12. Значение size_t присваивается указателю

```cpp
#include <cstddef>
std::size_t count{ 3 };
std::size_t* p{};
p = count;
```

<details>
<summary>Ответ</summary>

Не компилируется.
У `count` тип `std::size_t`, а для `p` требуется `std::size_t*`.
Размер числового типа не превращает его значения в указатели.
</details>

### 13. Двойной указатель с другим типом объекта

```cpp
#include <cstddef>
#include <cstdint>
std::size_t count{ 3 };
std::size_t* p{ &count };
std::int8_t** pp{};
pp = &p;
```

<details>
<summary>Ответ</summary>

Не компилируется.
У `&p` тип `std::size_t**`, а для `pp` требуется `std::int8_t**`.
Совпадения числа звёздочек недостаточно: типы объектов тоже должны совпадать.
</details>

### 14. Адрес size_t с неверным числом уровней указателя

```cpp
#include <cstddef>
std::size_t count{ 3 };
std::size_t** pp{};
pp = &count;
```

<details>
<summary>Ответ</summary>

Не компилируется.
У `&count` тип `std::size_t*`, а не `std::size_t**`.
Сначала создайте указатель на `count`, затем возьмите адрес этого указателя.
</details>

### 15. Присваивание size_t значения int8_t, прочитанного через указатель

```cpp
#include <cstddef>
#include <cstdint>
std::int8_t small{ 3 };
std::int8_t* p{ &small };
std::size_t count{};
count = *p;
```

<details>
<summary>Ответ</summary>

Компилируется.
У `*p` тип `std::int8_t`, поэтому числовое значение преобразуется в `std::size_t`.
В `count` записывается `3`; сам указатель не присваивается.
</details>
