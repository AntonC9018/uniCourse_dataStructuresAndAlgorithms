# Практика по массивам

## Практика

Используйте понятия из предыдущих работ, чтобы смоделировать каждую задачу и написать процедурные функции.
Для хранения фиксированного числа элементов используйте `std::array`.
Не используйте циклы.
Если в условии не сказано иное, считайте, что переданные индексы допустимы, а имеющихся количеств достаточно.
Для первых трёх задач приведены возможные решения.
Остальные задачи решите самостоятельно.

### 1. Выбор констант по индексу

В магазине есть три ценовые категории.
Их базовые цены составляют 10, 20 и 30 монет, а множители — 1, 1.5 и 2.
Получите цену и множитель для второй категории.

<details>
<summary>Возможное решение</summary>

```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 3> prices{ 10, 20, 30 };
    std::array<float, 3> multipliers{ 1.0f, 1.5f, 2.0f };
    int price{ prices[1] };
    float multiplier{ multipliers[1] };
    std::cout << price << std::endl;
    std::cout << multiplier << std::endl;
}
```

Программа выводит `20` и `1.5`.
Массивы содержат фиксированные настройки; индекс позволяет выбрать значение для одной категории.
Суффикс `f` задаёт этим десятичным литералам тип `float`.

</details>

### 2. Компиляция исходного кода

У исходного кода есть количество строк, а у машинного кода — количество инструкций.
Компилятор хранит коэффициенты числа инструкций на строку для трёх уровней оптимизации: 2.5, 1.5 и 1.25.
Скомпилируйте 101 строку исходного кода с третьим уровнем оптимизации.
В результате оставьте только целое число инструкций.

<details>
<summary>Возможное решение</summary>

```cpp
#include <array>
#include <cstddef>
#include <iostream>

struct SourceCode
{
    int lineCount;
};

struct MachineCode
{
    int instructionCount;
};

struct OptimizationLevel
{
    size_t index;
};

struct Compiler
{
    std::array<double, 3> instructionsPerLine;
};

MachineCode compile(Compiler* compiler, SourceCode source, OptimizationLevel level)
{
    double coefficient{ compiler->instructionsPerLine[level.index] };
    double estimate{ static_cast<double>(source.lineCount) * coefficient };
    return MachineCode{ static_cast<int>(estimate) };
}

int main()
{
    Compiler compiler{ std::array<double, 3>{ 2.5, 1.5, 1.25 } };
    SourceCode source{ 101 };
    OptimizationLevel level{ 2 };
    MachineCode result{ compile(&compiler, source, level) };
    std::cout << result.instructionCount << std::endl;
}
```

Программа выводит `126`.
Уровень выбирает коэффициент `1.25`; умножение даёт `126.25`, а преобразование в `int` отбрасывает дробную часть.
Приведение числа строк к `double` меняет тип выражения, но не тип `source.lineCount`.

</details>

### 3. Отсеки холодильника

В холодильнике есть три отсека, в каждом из которых хранятся молоко и яйца.
Изначально в отсеках находятся `(100 мл, 2 яйца)`, `(300 мл, 0 яиц)` и `(0 мл, 5 яиц)`.
Перелейте 120 мл из второго отсека в пустую чашку.
Выведите оставшееся во втором отсеке молоко, содержимое чашки и число яиц в первом отсеке.

<details>
<summary>Возможное решение</summary>

```cpp
#include <array>
#include <cstddef>
#include <iostream>

struct Slot
{
    int milkMl;
    int eggs;
};

struct Fridge
{
    std::array<Slot, 3> slots;
};

struct Cup
{
    int milkMl;
};

void pourMilk(Fridge* fridge, size_t slotIndex, Cup* cup, int amountMl)
{
    fridge->slots[slotIndex].milkMl -= amountMl;
    cup->milkMl += amountMl;
}

int main()
{
    Fridge fridge{
        std::array<Slot, 3>{ Slot{ 100, 2 }, Slot{ 300, 0 }, Slot{ 0, 5 } }
    };
    Cup cup{};
    pourMilk(&fridge, 1, &cup, 120);
    std::cout << fridge.slots[1].milkMl << std::endl;
    std::cout << cup.milkMl << std::endl;
    std::cout << fridge.slots[0].eggs << std::endl;
}
```

Программа выводит `180`, `120` и `2`.
Функция через указатели изменяет выбранный отсек и чашку, переданную вызывающим кодом.
Остальные отсеки и количество яиц остаются без изменений.

</details>

### 5. Хранение в байтовом буфере (задача повышенной сложности)

Храните несколько небольших структур в байтовом буфере фиксированного размера.
Число использованных байтов учитывайте с помощью позиции типа `size_t`.
Получайте `sizeof` элемента как параметр, резервируйте место и сдвигайте текущую позицию.
Возвращайте адрес, который вызывающий код преобразует с помощью `reinterpret_cast`.
Учитывайте выравнивание и доступную ёмкость буфера.
Покажите, как элементы двух разных типов занимают отдельные области памяти.

Для этой задачи нужны дополнительные знания о выравнивании и времени жизни объектов.
Используйте память с подходящим выравниванием и начинайте время жизни каждого объекта,
например с помощью размещающего `new`, прежде чем обращаться к его полям.
Само по себе приведение адреса не создаёт объект.
Ограничьтесь тривиальными структурами.
