# Практика по массивам

## Практика

Используйте понятия из предыдущих работ, чтобы смоделировать каждую задачу и написать процедурные функции.
Для хранения фиксированного числа элементов используйте `std::array`.
Не используйте циклы.
Если в условии не сказано иное, считайте, что переданные индексы допустимы, а имеющихся количеств достаточно.
У первых трёх задач и продвинутой задачи о хранении в байтах есть возможные решения.
Остальные задачи решите самостоятельно.

### 1. Кормление рыб в аквариумах

В трёх аквариумах живут 10, 20 и 30 рыб.
Рыбам в них нужно соответственно 1, 1.5 и 2 грамма корма на рыбу в день.
Сообщите число рыб и суточную порцию корма на одну рыбу во втором аквариуме.

<details>
<summary>Возможное решение</summary>

```cpp
#include <array>
#include <iostream>

int main()
{
    std::array<int, 3> fishCounts{ 10, 20, 30 };
    std::array<float, 3> feedGramsPerFish{ 1.0f, 1.5f, 2.0f };
    int fishCount{ fishCounts[1] };
    float feedPortion{ feedGramsPerFish[1] };
    std::cout << fishCount << std::endl;
    std::cout << feedPortion << std::endl;
}
```

Печатает `20` и `1.5`.
Индекс выбирает число рыб и норму кормления для одного и того же аквариума.
Суффикс `f` задаёт тип `float` для дробных литералов.

</details>

### 2. Компиляция исходного кода

У исходного кода есть число строк, а у машинного кода — число инструкций.
Есть три уровня оптимизации: без оптимизации, базовая и полная.
Отношение числа машинных инструкций к числу строк зависит от компилятора и уровня оптимизации.
В этой упрощённой модели для MSVC коэффициенты равны 2.5, 1.5 и 1.25, а для GCC — 3, 1.75 и 1.
Скомпилируйте 101 строку обоими компиляторами с полной оптимизацией, оставляя только целые инструкции.

<details>
<summary>Возможное решение</summary>

```cpp
#include <array>
#include <cstddef>
#include <iostream>

struct SourceCode
{
    int lineCount;
};

struct MachineCode
{
    int instructionCount;
};

struct OptimizationLevel
{
    size_t index;
};

struct Compiler
{
    std::array<double, 3> instructionsPerLine;
};

MachineCode compile(Compiler* compiler, SourceCode source, OptimizationLevel level)
{
    double coefficient{ compiler->instructionsPerLine[level.index] };
    double estimate{ static_cast<double>(source.lineCount) * coefficient };
    return MachineCode{ static_cast<int>(estimate) };
}

int main()
{
    Compiler msvc{ std::array<double, 3>{ 2.5, 1.5, 1.25 } };
    Compiler gcc{ std::array<double, 3>{ 3.0, 1.75, 1.0 } };
    SourceCode source{ 101 };
    OptimizationLevel level{ 2 };
    MachineCode msvcResult{ compile(&msvc, source, level) };
    MachineCode gccResult{ compile(&gcc, source, level) };
    std::cout << msvcResult.instructionCount << std::endl;
    std::cout << gccResult.instructionCount << std::endl;
}
```

Программа выводит `126` и `101`.
Для MSVC уровень выбирает коэффициент `1.25`; умножение даёт `126.25`.
Преобразование в `int` отбрасывает дробную часть.
Для GCC тот же уровень выбирает `1`, поэтому получается `101` инструкция.
Приведение числа строк к `double` меняет тип выражения, но не тип `source.lineCount`.

</details>

### 3. Отсеки холодильника

В холодильнике три ячейки, в каждой стоит одна бутылка молока.
В бутылках 100 мл, 300 мл и 200 мл.
Налейте 120 мл из второй бутылки в пустую чашку.
Сообщите остаток в этой бутылке, содержимое чашки и количество молока в первой бутылке.

<details>
<summary>Возможное решение</summary>

```cpp
#include <array>
#include <cstddef>
#include <iostream>

struct MilkBottle
{
    int milkMl;
};

struct Fridge
{
    std::array<MilkBottle, 3> slots;
};

struct Cup
{
    int milkMl;
};

void pourMilk(Fridge* fridge, size_t slotIndex, Cup* cup, int amountMl)
{
    fridge->slots[slotIndex].milkMl -= amountMl;
    cup->milkMl += amountMl;
}

int main()
{
    Fridge fridge{
        std::array<MilkBottle, 3>{ MilkBottle{ 100 }, MilkBottle{ 300 }, MilkBottle{ 200 } }
    };
    Cup cup{};
    pourMilk(&fridge, 1, &cup, 120);
    std::cout << fridge.slots[1].milkMl << std::endl;
    std::cout << cup.milkMl << std::endl;
    std::cout << fridge.slots[0].milkMl << std::endl;
}
```

Программа выводит `180`, `120` и `100`.
Функция через указатели изменяет выбранный отсек и чашку, переданную вызывающим кодом.
Остальные бутылки не меняются.

</details>

### 17. Хранение в байтах (продвинутый уровень)

Храните монету и результат измерения в фиксированном буфере байтов,
учитывая число занятых байтов переменной типа `size_t`.
Выделяйте место по размеру и выравниванию объекта и возвращайте адрес, который вызывающий код преобразует через
`reinterpret_cast`.
Считайте, что в буфере хватает места для обоих объектов и промежутков для выравнивания.

<details>
<summary>Возможное решение</summary>

```cpp
#include <array>
#include <cstddef>
#include <iostream>
#include <memory>
#include <new>

struct Storage
{
    alignas(std::max_align_t) std::array<std::byte, 64> bytes{};
    size_t position{};
};

void* reserve(Storage* storage, size_t itemSize, size_t itemAlignment)
{
    void* address{ storage->bytes.data() + storage->position };
    size_t remaining{ storage->bytes.size() - storage->position };
    [[maybe_unused]] void* aligned{ std::align(itemAlignment, itemSize, address, remaining) };
    storage->position = storage->bytes.size() - remaining + itemSize;
    return address;
}

struct Coin
{
    int value;
};

struct Measurement
{
    double value;
};

int main()
{
    Storage storage{};
    void* coinAddress{ reserve(&storage, sizeof(Coin), alignof(Coin)) };
    Coin* coin{ reinterpret_cast<Coin*>(coinAddress) };
    [[maybe_unused]] Coin* createdCoin{ new (coin) Coin{ 5 } };

    void* measurementAddress{ reserve(&storage, sizeof(Measurement), alignof(Measurement)) };
    Measurement* measurement{ reinterpret_cast<Measurement*>(measurementAddress) };
    [[maybe_unused]] Measurement* createdMeasurement{ new (measurement) Measurement{ 2.5 } };

    std::cout << coin->value << std::endl;
    std::cout << measurement->value << std::endl;
    std::cout << storage.position << std::endl;
}
```

Печатает `5`, `2.5` и обычно `16` занятых байтов.
`sizeof` задаёт размер объекта, а `alignof` — требуемое выравнивание.
`std::align` при необходимости сдвигает `address` вперёд и уменьшает `remaining` на размер этого промежутка.
Новая позиция учитывает и промежуток, и место для объекта.
`reinterpret_cast` задаёт тип указателя; размещающий `new` начинает время жизни объекта и инициализирует его поля.

> Этот продвинутый пример вводит выравнивание и время жизни объектов, которых не было в предыдущих лабах.
> Считаем, что места хватает; универсальный аллокатор также обрабатывал бы нулевой указатель от `std::align`.
> Занятый объём зависит от размеров и выравнивания; этим тривиальным объектам не нужен явный вызов деструктора.

</details>
