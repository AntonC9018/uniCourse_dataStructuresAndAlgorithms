# C++ массивы (`std::array`)

- [Информация](../../../en/06_arrays/doc.md)

## Концепты

- Преимущество C++ массивов над C массивами
- Копирование и инициализация массивов
- Индексирование C++ массивов
- `data`
- Получение ссылок на элементы массива
- Получение адресов элементов массива
- Типы данных кроме `int` под элементы массива

- Константные массивы, их копирование и чтение через `data`
- Размеры, известные во время компиляции, как аргументы шаблона

## Примеры

### 1. С++ массивы
```cpp
std::array<int, 2> arr{ 1, 2 };
int* pa = a.data();
int& b = *pa;
pa += 1;
std::cout << b << std::endl;
```
<details>
<summary>

Что такое `data`?</summary>

`a.data()` дает адрес первого элемента из массива 
(`&a[0]`, `a[0]` дает ссылку, потом берем адрес из ссылки).
</details>

<details>
<summary>Ответ</summary>

`b` будет продолжать ссылаться на первый элемент, несмотря на то, что указатель обновился.
</details>

### 2. Инициализация C++ массивов (1)
```cpp
std::array<int, 2> arr{ 1, 2 };
std::array<int, 2> other{ 3, 4 };
arr = other;
```

<details>
<summary>Ответ</summary>

Тут каждый элемент копириуется из `other` в `arr`.
</details>

### 3. Инициализация C++ массивов (2)
```cpp
std::array<int, 2> arr{ 1, 2 };
std::array<int, 2> other{ arr };
```

<details>
<summary>Ответ</summary>

Тут тоже, но при создании `other`.
</details>

### 4. Константный C++ массив

```cpp
const std::array<int, 2> arr{ 1, 2 };
arr[0] = 3;
```

<details>
<summary>Ответ</summary>

Программа не скомпилируется: индексирование константного `std::array` даёт доступ к его элементам только для чтения.
`arr[0]` можно читать, но нельзя перезаписать.
Это [правило для константных объектов](13_const.md), применённое к C++ массиву.
</details>

### 5. Копирование константного C++ массива

```cpp
const std::array<int, 2> arr{ 1, 2 };
std::array<int, 2> other = arr;
other[0] = 3;
std::cout << arr[0] << std::endl;
std::cout << other[0] << std::endl;
```

<details>
<summary>Ответ</summary>

Выведутся `1` и `3`.
Весь массив копируется в неконстантный объект `other`.
Как и при копировании константной структуры, копию можно менять независимо от оригинала.
</details>

### 6. Ссылка на массив
```cpp
std::array<int, 2> arr{ 1, 2 };
std::array<int, 2>& other{ arr };
other[0] = 3;
std::cout << arr[0] << std::endl;
```

<details>
<summary>Ответ</summary>

Здесь иллюстрируется создание ссылки на объект типа С++ массива.
`other` как бы заменяете на `arr`.
</details>

### 7. Адрес массива
```cpp
std::array<int, 2> arr{ 1, 2 };
std::array<int, 2>* p{ &arr };
*p = { 3, 4 };
std::cout << arr[0] << std::endl;
std::cout << arr[1] << std::endl;
```

<details>
<summary>Ответ</summary>

`p` будет содержать адрес начала всего объекта массива.
Объект массива покрывает все его элементы.

Здесь, изначальные элементы перезаписываются на `3, 4`.
</details>

### 8. Dereference адреса массива
```cpp
std::array<int, 2> arr{ 1, 2 };
std::array<int, 2>* p{ &arr };
std::array<int, 2> arr1{ *p };
arr1[0] = 3;
arr1[1] = 4;
std::cout << arr[0] << std::endl;
std::cout << arr[1] << std::endl;
```

<details>
<summary>Ответ</summary>

Тип у `p` это `std::array<int, 2>`, выражение `*p` даст значение
типа `std::array<int, 2>`, то есть в `arr1` попадет копия всего массива

Поскольку `arr1` это копия, ее изменения не повлияют на `arr`.
</details>

### 9. Ссылка на элемент массива
```cpp
std::array<int, 2> arr{ 1, 2 };
int& a = arr[0];
a = 3;
```

<details>
<summary>Ответ</summary>

`a = 3` перезаписывает первый элемент массива, 
поскольку в `a` была сохранена ссылка на 1 элемент (на объект внутри массива).
</details>

### 10. Индексирование элементов из адреса
```cpp
std::array<int, 2> arr{ 1, 2 };
std::array<int, 2>* p{ &arr };
(*p)[0] = 3;
(*p)[1] = 4;
std::cout << arr[0] << std::endl;
std::cout << arr[1] << std::endl;
```

<details>
<summary>Ответ</summary>

Здесь, `*p` — это выражение типа `std::array<int, 2>&`, то есть дает ссылку на массив,
на память переменной `arr` (потому что в `p` адрес `arr`).

Индексирование относительно `(*p)` будет давать *ссылки на элементы в массиве*.
Например, тип выражения `(*p)[0]` — это `int&`, а ссылаться это будет 
на первый элемент в массиве, в переменной `arr`.

Перезапись также будет применяться к элементам `arr`.
</details>

### 11. Адрес элемента через `data`
```cpp
std::array<int, 2> arr { 1, 2 };
int& arr1 = *(p.data() + 1)
```

<details>
<summary>Ответ</summary>

Аналогично коду выше, только выражение сложнее.
Тут в `arr1` попадает адрес `arr[1]`.
</details>

### 12. data у константного C++ массива

```cpp
const std::array<int, 2> arr{ 1, 2 };
int* p = arr.data();
```

<details>
<summary>Ответ</summary>

Программа не скомпилируется: для этого константного массива `arr.data()` возвращает `const int*`.
Если инициализировать `int*` этим адресом, будет отброшен `const` у объекта, на который указывает указатель.
Для чтения элементов можно написать `const int* p = arr.data()`; записывать через этот указатель по-прежнему нельзя.
</details>

### 13. Взаиморасположение базового адреса и самого объекта массива
```cpp
std::array<int, 2> arr { 1, 2 };
ptrdiff_t diff { reinterpret_cast<uint8_t*>(arr.data()) - reinterpret_cast<uint8_t*>(&arr) };
std::cout << diff << std::endl;
```

<details>
<summary>Ответ</summary>

Начало всего массива находится там же, где и первый элемент массива.
**Массив `std::array` это и есть его элементы**.

Выведется 0.
</details>

### 14. Матрицы (двумерные массивы)
```cpp
std::array<std::array<int, 2>, 3> arr{ 
    std::array{ 1, 2 },
    { 3, 4 },
    { 5, 6 },
};
std::array<int, 2> firstRow { arr[0] };
std::array<int, 2> lastRow { arr[2] };
arr[0][0] = 7;
arr[2][1] = 8;
arr[1] = { 9, 10 };
```

<details>
<summary>Ответ</summary>

Тут иллюстрируется использование массива, где тип элемента не `int`, а массив.
Каждый элемент массива по сути теперь хранит в себе по два инта.

> В инициализации `arr` необходимо указать `std::array`, 
> потому что иначе компилятор не может определить тип элемента из инициализации.
> Ему нужно слегка помочь.
>
> Механизм этого вам пока не обязательно понимать.
</details>

<details>
<summary>Можно ли использовать пользовательский тип как элемент массива?</summary>

Можно. Попробуйте определить тип, например:
```cpp
struct Item
{
    int f1;
    int f2;
};
```

И использовать его в качестве типа элемента, вот так:
```cpp
std::array<Item, 3> arr{
    Item{ 1, 2 },
    { 3, 4 },
    { 5, 6 },
};
```
</details>

### 15. Размер, известный во время компиляции, как аргумент шаблона

```cpp
#include <array>
#include <iostream>

struct Sizes
{
    int count;
};

int main()
{
    const int count = 2;
    std::array<int, count> a{ 1, 2 };

    constexpr Sizes sizes{ 3 };
    std::array<int, sizes.count> b{ 3, 4, 5 };

    std::cout << a[1] << std::endl;
    std::cout << b[2] << std::endl;
}
```

<details>
<summary>Ответ</summary>

Выведутся `2` и `5`.
В `std::array<T, N>` аргумент `T` задаёт тип элемента, а `N` — количество элементов.
Это аргументы шаблона: здесь аргумент размера должен быть константным выражением, известным во время компиляции.
И локальный `const int`, инициализированный числом `2`, и поле структуры с `constexpr` удовлетворяют этому требованию.

Здесь вместо числовых литералов используются размеры из [лабораторной по const](13_const.md).
Размер, полученный от пользователя, не подошёл бы, даже если его переменная объявлена с `const`.
</details>
