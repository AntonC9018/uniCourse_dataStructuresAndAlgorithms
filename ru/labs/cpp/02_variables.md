## Примеры на понимание

Объясните, что произойдет в следующих отрезках кода.
Также, запустите данный код, чтобы убедиться в правильности вашей логики.

> Там, где `main` не был расписан, код помещается в типичный основной файл:
> ```cpp
> #include <iostream>
> #include <cstdint>
>
> int main()
> {
>     // сюда
> }
> ```

### 1. Определение переменной
```cpp
int a = 5;
std::cout << a << std::endl;
```

<details>
<summary>Создание переменной</summary>

В `int a = 5;` слово `int` задаёт тип, `a` — имя, а `5` — начальное значение. Тип `int` хранит целые числа. Следующая строка считывает и печатает значение `a`.
</details>

<details>
<summary>Ответ</summary>

Печатает `5`; у `a` тип `int`.
</details>

### 2. Объявление переменной
```cpp
int a;
std::cout << a << std::endl;
```

<details>
<summary>Задайте значение перед чтением</summary>

`int a;` создаёт локальную переменную без начального значения. Не считывайте её, пока не запишете в неё значение. Здесь строка печати как раз пытается это сделать. Например, `int a = 0;` задаёт известное начальное значение.
</details>

<details>
<summary>Ответ</summary>

Нельзя рассчитывать на определённый вывод.
</details>

<details>
<summary>Почему пробный запуск не доказывает, что так можно</summary>

В версиях C++ до C++23 включительно это называется неопределённым поведением: язык не обещает никакого конкретного результата. Даже если один раз выведется `0`, полагаться на него нельзя. Предупреждения компилятора, например с флагом `-Wall`, помогают заметить ошибку; `-Werror` превращает предупреждения в ошибки.
</details>

### 3. Определение переменной с тем же именем
```cpp
int a = 5;
int a = 6;
std::cout << a << std::endl;
```

<details>
<summary>Создание переменной и изменение значения</summary>

Запись `int a` создаёт переменную. В том же блоке нельзя создать ещё одну переменную с тем же именем, даже другого типа. Чтобы изменить существующее значение, напишите `a = 6;` без `int`.
</details>

<details>
<summary>Ответ</summary>

Не компилируется.
</details>

### 4. Присваивание переменной к другой переменной
```cpp
int a = 5;
int b = 6;
a = b;
b = 7;
std::cout << a << std::endl;
```

<details>
<summary>Присваивание копирует текущее значение</summary>

`a = b` копирует текущее значение `b` в `a`. Переменные не остаются связанными. Здесь копируется `6`; последующее изменение `b` на `7` не меняет `a`.
</details>

<details>
<summary>Ответ</summary>

Печатает `6`.
</details>

### 5. Литералы, переменные и операторы — это выражения
```cpp
int a = 5;
int b = a;
int c = a + 6;
std::cout << b << std::endl;
std::cout << c << std::endl;
```

<details>
<summary>Выражение даёт значение</summary>

Выражение — это код, который даёт значение. Число вроде `5` даёт само себя; чтение `a` даёт сохранённое в ней значение; `a + 6` складывает два значения. Здесь в `a` хранится `5`, поэтому в `b` записывается `5`, а в `c` — `11`.
</details>

<details>
<summary>Ответ</summary>

Печатает `5` и `11` на отдельных строках.
</details>

### 6. Присваивание выражения к переменной

Какие выражения есть в этом фрагменте кода?

```cpp
int a = 5;
int b = a + 6;
a = 7;
std::cout << b << std::endl;
```

<details>
<summary>Сохраняется результат, а не формула</summary>

В `int b = a + 6;` сначала вычисляется `a + 6`, а затем результат записывается в `b`. Здесь это `5 + 6`, то есть `11`. Последующее изменение `a` не пересчитывает `b`.
</details>

<details>
<summary>Ответ</summary>

Печатает `11`. Записанные в коде числа, чтения переменных, `a + 6`, `a = 7` и выражение вывода — это выражения.
</details>

<details>
<summary>Присваивание тоже является выражением</summary>

`a = 7` меняет `a` и также даёт присвоенное значение. Поэтому можно написать:
```cpp
int c = (a = 7);
```
После этого и в `a`, и в `c` будет `7`.
</details>

### 7. Строковое значение
```cpp
int a = "abc";
```

<details>
<summary>Значение должно подходить типу</summary>

Тип `int` хранит целые числа. Текст `"abc"` не является целым числом и не может быть начальным значением `int`.
</details>

<details>
<summary>Ответ</summary>

Не компилируется.
</details>

### 8. Обратная запись выражения вывода

```cpp
"ggg" >> std::cout;
```

<details>
<summary>Порядок в инструкции печати важен</summary>

Поставьте `std::cout` слева и используйте `<<`: `std::cout << "ggg";`. Перестановка частей и замена `<<` на `>>` не дают того же результата.
</details>

<details>
<summary>Ответ</summary>

Не компилируется.
</details>

### 9. Универсальная инициализация
```cpp
int a{5};
```

<details>
<summary>Начальное значение в фигурных скобках</summary>

`int a{5};` задаёт переменной `a` начальное значение `5`, как и `int a = 5;`. Скобки также помогают заметить ошибки: `int a{5.6};` не допускается, потому что `int` не может сохранить дробную часть.
</details>

<details>
<summary>Ответ</summary>

Компилируется; у `a` тип `int` и значение `5`.
</details>

<details>
<summary>Что происходит без фигурных скобок</summary>

`int a = 5.6;` может скомпилироваться, но сохранит только `5`: дробная часть потеряется. Скобки в `int a{5.6};` заставляют компилятор отклонить такую потерю.
</details>

### 10. Пустая инициализация
```cpp
int a{};
std::cout << a << std::endl;
```

<details>
<summary>Пустые скобки задают int ноль</summary>

`int a{};` задаёт `a` начальное значение `0`. Это отличается от `int a;`, где начальное значение не задаётся. Здесь значение `a` можно считывать.
</details>

<details>
<summary>Ответ</summary>

Печатает `0`.
</details>

### 11. Присваивание пустых фигурных скобок

```cpp
int a{ 7 };
a = {};
std::cout << a << std::endl;
```

<details>
<summary>Присваивание пустых скобок</summary>

Для `int` запись `a = {};` записывает в `a` ноль. Она заменяет старое значение `7`, а не оставляет переменную без значения.
</details>

<details>
<summary>Ответ</summary>

Печатает `0`.
</details>

### 12. Выражение int{}

```cpp
int a{ 7 };
a = int{};
int b = int{};
std::cout << a << std::endl;
std::cout << b << std::endl;
```

<details>
<summary>Использование int{} как значения</summary>

`int{}` — выражение типа `int` со значением `0`. Его можно использовать для изменения переменной или задания начального значения новой переменной. Здесь и `a`, и `b` получают `0`.
</details>

<details>
<summary>Ответ</summary>

Дважды печатает `0`.
</details>

### 13. Оператор `sizeof`
```cpp
std::cout << sizeof(int) << std::endl;
std::cout << sizeof(uint8_t) << std::endl;
int a;
std::cout << sizeof(a) << std::endl;
```

<details>
<summary>Размер в байтах</summary>

`sizeof` даёт размер типа или переменной в байтах. Поскольку `a` имеет тип `int`, `sizeof(a)` равно `sizeof(int)`. Значение `a` не считывается, поэтому отсутствие начального значения здесь не мешает. `uint8_t` занимает один байт; размер `int` может зависеть от системы.
</details>

<details>
<summary>Ответ</summary>

В системе с 4-байтовым `int` печатает `4`, `1` и `4`. Первое и последнее значения зависят от размера `int`.
</details>

### 14. `auto`

Какой тип будет у `a` в данном примере?
```cpp
auto a = 5;
```

<details>
<summary>Выбор типа компилятором</summary>

`auto` просит компилятор выбрать тип по начальному выражению. У числа `5` тип `int`, поэтому `a` получает тип `int`. Тип выбирается один раз и не может измениться позже.
</details>

<details>
<summary>Ответ</summary>

У `a` тип `int` и значение `5`.
</details>

<details>
<summary>Тип остаётся прежним</summary>

Автоматический выбор типа не позволяет менять его позже:
```cpp
auto a = 5;
a = "abc"; // ошибка: a по-прежнему имеет тип int
```
</details>

### 15. `auto` без инициализации
```cpp
auto a;
a = 5;
```

<details>
<summary>Для auto нужно начальное выражение</summary>

Компилятор должен выбрать тип уже в `auto a;`, но начального выражения для этого нет. Присваивание `5` на следующей строке не помогает. Вместо этого напишите `auto a = 5;`.
</details>

<details>
<summary>Ответ</summary>

Не компилируется.
</details>

### 16. `auto` с универсальной инициализацией

```cpp
auto a{ 5 };
```

<details>
<summary>auto с фигурными скобками</summary>

Когда в этих скобках одно выражение, `auto` выбирает его тип. Здесь у `5` тип `int`, как и в `auto a = 5;`.
</details>

<details>
<summary>Ответ</summary>

У `a` тип `int` и значение `5`.
</details>

### 17. `auto` от другой переменной
```cpp
int a{ 5 };
auto b{ a + 5 };
```

<details>
<summary>auto использует всё выражение</summary>

Начальное выражение не обязательно должно быть числом, записанным прямо в коде. Здесь `a + 5` складывает два значения `int` и даёт `10`, тоже типа `int`. Этот тип и выбирается для `b`.
</details>

<details>
<summary>Ответ</summary>

У `b` тип `int` и значение `10`.
</details>

### 18. Смена переменных
```cpp
int a { 1 };
int b { 2 };
a = b;
b = a;
std::cout << a << std::endl;
std::cout << b << std::endl;
```

<details>
<summary>Перезапись теряет старое значение</summary>

`a = b` заменяет `1` в `a` на `2`. Затем `b = a` копирует эту `2` в `b`. Исходная `1` уже потеряна, поэтому эти присваивания не могут поменять значения местами.
</details>

<details>
<summary>Ответ</summary>

Дважды печатает `2`; значения не меняются местами.
</details>

<details>
<summary>Как действительно поменять значения местами</summary>

Сохраните старое значение `a` перед перезаписью:
```cpp
int temp{ a };
a = b;
b = temp;
```
</details>
