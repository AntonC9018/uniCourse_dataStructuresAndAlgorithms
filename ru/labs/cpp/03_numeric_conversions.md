### 1. `auto` и `static_cast`

```cpp
auto a{ static_cast<uint8_t>(5) };
```

<details>
<summary>Изменение типа значения</summary>

`static_cast<uint8_t>(5)` преобразует значение `5` в тип `uint8_t`. Тип в `<...>` задаёт, во что преобразовать, а выражение в `(...)` даёт значение. После этого `auto` выбирает для `a` тип `uint8_t`.
</details>

<details>
<summary>Ответ</summary>

У `a` тип `uint8_t` и значение `5`.
</details>

### 2. Приведение меняет тип выражения

```cpp
int value{ 7 };
double half{ static_cast<double>(value) / 2 };
int integerHalf{ value / 2 };
std::cout << value << std::endl;
std::cout << half << std::endl;
std::cout << integerHalf << std::endl;
```

<details>
<summary>Деление целых и дробных чисел</summary>

Преобразование `value` в `double` даёт `7.0` для первого деления, поэтому деление на `2` даёт `3.5`. Сама переменная `value` не меняется. В `value / 2` оба числа по-прежнему целые, поэтому дробная часть отбрасывается и получается `3`.
</details>

<details>
<summary>Ответ</summary>

Печатает `7`, `3.5` и `3` на отдельных строках.
</details>

<details>
<summary>Почему второе число тоже становится double</summary>

Когда одна сторона этого деления имеет тип `double`, C++ преобразует вторую сторону в `double` тоже. Здесь первое деление работает как `7.0 / 2.0`.
</details>

### 3. `static_cast` в больший тип

```cpp
uint8_t a{ 5 };
int b{ static_cast<int>(a) };
```

<details>
<summary>Преобразование в более вместительный тип</summary>

Любое значение `uint8_t` помещается в `int`, поэтому это преобразование сохраняет число. Здесь `b` получает ту же `5`, что и `a`. Можно также написать `int b{ a };`: компилятор выполнит преобразование автоматически.
</details>

<details>
<summary>Ответ</summary>

У `b` тип `int` и значение `5`.
</details>

### 4. `static_cast` отрицательного числа в больший тип

```cpp
int8_t a{ -3 };
int b{ static_cast<int>(a) };
```

<details>
<summary>Сохранение отрицательного значения</summary>

В `int` помещается любое значение `int8_t`, в том числе отрицательное. Преобразование `a` сохраняет значение `-3`: дополнительные биты не меняют знак числа.
</details>

<details>
<summary>Ответ</summary>

У `b` тип `int` и значение `-3`.
</details>

<details>
<summary>Как биты сохраняют отрицательное число</summary>

Для отрицательного числа добавленные старшие биты заполняются единицами. Например, `-3` записывается как `1111 1101` в 8 битах и как `1111 1111 1111 1111 1111 1111 1111 1101` в 32 битах.
</details>

### 5. `static_cast`
```cpp
#include <cstdint>
#include <iostream>

int main()
{
    uint32_t a{ 256 };
    uint8_t b{ static_cast<uint8_t>(a) };
    uint32_t c{ b };
    std::cout << c << std::endl;
}
```

<details>
<summary>Сохранение только восьми битов</summary>

`uint8_t` хранит значения от `0` до `255`. При преобразовании большего числа в этот тип сохраняются только младшие 8 битов. Здесь `256` записывается в двоичной системе как `1 0000 0000`. Последние 8 битов — `0000 0000`, то есть `0`. Копирование в `c` его не меняет.
</details>

<details>
<summary>Ответ</summary>

Печатает `0`.
</details>

<details>
<summary>Что будет, если в <code>a</code> сохранить другое значение?</summary>

- Значение 257: Сохранится `1 0000 0001`, что оставит `0000 0001` при отсечении.
- Значение 258: Сохранится `1 0000 0010`, что оставит `0000 0010` при отсечении.
- Значение 511: Сохранится `1 1111 1111`, что оставит `1111 1111` при отсечении.
- Значение 512: Сохранится `10 0000 0000`, что оставит `0000 0000` при отсечении.
</details>

<details>
<summary>Что будет без явного преобразования?</summary>

`uint8_t b{ a };` не допускается, потому что значение может не поместиться. Запись `static_cast<uint8_t>(a)` явно указывает компилятору выполнить преобразование, даже если часть битов потеряется.
</details>

### 6. Побитовая операция (продвинутый уровень)
```cpp
#include <cstdint>
#include <iostream>

int main()
{
    uint8_t a{ 0 };
    uint8_t b{ ~a };
    int32_t c{ b };
    std::cout << c;
}
```

<details>
<summary>Инверсия битов</summary>

`~` меняет каждый бит `0` на `1`, а каждый `1` — на `0`. Например, `1010 0011` превращается в `0101 1100`. Есть тонкость: C++ сначала преобразует маленькое значение `uint8_t` в `int`, поэтому `~a` имеет тип `int`, а не 8-битный тип. Скобки в `uint8_t b{ ~a };` запрещают такое обратное преобразование в восемь битов.
</details>

<details>
<summary>Ответ</summary>

Не компилируется по правилам C++: преобразование в `uint8_t b{ ~a };` не допускается.
</details>

<details>
<summary>Как сохранить восемь инвертированных битов</summary>

Явно запросите обратное преобразование в `uint8_t`:
```cpp
uint8_t b{ static_cast<uint8_t>(~a) };
```
Младшие 8 битов будут `1111 1111`, то есть `255`. После этого изменения программа напечатает `255`.
</details>

### 7. Смена знака (продвинутый уровень)
```cpp
#include <cstdint>
#include <iostream>

int main()
{
    uint8_t a{ 127 };
    int8_t b{ static_cast<int8_t>(a) };
    int32_t c{ b };
    std::cout << c;
}
```

<details>
<summary>Преобразование между числами без знака и со знаком</summary>

`uint8_t` хранит числа от `0` до `255`, а `int8_t` — от `-128` до `127`. Значение `127` помещается в оба типа, поэтому преобразование сохраняет число. Копирование в более вместительный `int32_t` также сохраняет `127`.
</details>

<details>
<summary>Ответ</summary>

Печатает `127`.
</details>

<details>
<summary>Что происходит с другими значениями?</summary>

Начиная с C++20, преобразование `128` (`1000 0000`) в `int8_t` даёт `-128`: те же биты представляют отрицательное число в типе со знаком. До C++20 результат такого преобразования значения вне диапазона зависит от компилятора. Значение, которое помещается, как `127` здесь, не меняется.
</details>
