Здесь имеется в виду вектор из математики, а не вектор как динамический массив.
В STL для числовых массивов с поэлементными операциями есть шаблонный класс —
[`std::valarray`](https://en.cppreference.com/w/cpp/numeric/valarray).
Он умеет применять арифметику ко всем элементам сразу (`a + b`, `a * 2` и так далее),
но это не полноценный класс математического вектора:
API линейной алгебры (скалярное произведение, норма и тому подобное) в него не входит.
