## Tasks

- Install GCC using msys2, WSL, or Zig.
- Run the compiler (`g++`) from the console.
- Compile a source file successfully.
- Run the resulting executable.
- Configure PATH so that `g++` can be invoked without specifying its full path.
- Use the `-o` flag to specify the output file.
