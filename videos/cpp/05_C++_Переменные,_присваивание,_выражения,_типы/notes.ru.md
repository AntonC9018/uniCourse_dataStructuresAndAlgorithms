# Переменные, присваивание, выражения и типы

[00:00:00](https://www.youtube.com/watch?v=6ML34OuwZrc&t=0s) Этот урок собирает небольшую программу из именованного хранилища: создаём переменную, записываем в неё число, копируем это число, вычисляем новое значение и выбираем тип, который определяет способ хранения и вывода.

Термины, которые понадобятся:

- **Ячейка памяти, адрес и переменная:** ячейка — это место размером в один байт на рисунке памяти в уроке; её адрес задаёт положение. Переменная даёт коду программы имя для объекта, который хранит значение.
- **Абстракция:** более простой способ пользоваться чем-то, не управляя внутренними деталями. Имя переменной скрывает детали поиска нужного места хранения.
- **Объявление и определение:** объявление вводит имя и тип; локальные объявления здесь одновременно являются определениями, создающими переменные. **Инициализация** задаёт значение в момент создания переменной.
- **Значение, чтение, запись и присваивание:** значение — это хранимое число в этих примерах. Чтение его получает; запись его заменяет. Присваивание, записываемое знаком `=`, помещает результат справа в уже существующее место назначения слева.
- **Выражение, вычисление, оператор и операнд:** выражение при вычислении даёт значение. Такой оператор, как `+`, выполняет операцию над своими операндами — выражениями, которые он объединяет. Скобки группируют выражение.
- **Тип, псевдоним и целое число:** тип определяет допустимые значения, требования к хранению и поддерживаемое поведение. Псевдоним — другое имя для того же типа. Целое число — это число без дробной части; `int` — тип целого числа, который используется первым.
- **Бит, байт и ширина:** бит хранит 0 или 1. Здесь байт содержит восемь бит, а ширина типа считает его биты значения. **Знаковые** целые включают отрицательные значения; **беззнаковые** начинаются с нуля. `uint8_t` — беззнаковый целочисленный тип ровно с восемью битами, где он доступен.
- **Заголовочный файл и компилятор:** заголовочный файл предоставляет объявления, нужные программе; `#include` делает его содержимое доступным. Компилятор переводит исходный код и выдаёт диагностику, включая предупреждения и ошибки.
- **Преобразование и переполнение:** преобразование меняет значение на другой тип. В записи выход за диапазон байта называется «переполнением»; здесь хранимое число оборачивается в диапазон байта.
- **Вывод, код символа и перегрузка:** вывод отправляет данные в место назначения, например в терминал. `std::cout` — стандартный поток вывода C++, а `<<` вставляет в него значение. Код символа — число, представляющее символ; в примерах используется таблица ASCII. Перегрузка даёт разные поведения под одним и тем же именем операции, и выбор между ними делается по типам.
- **Функция и тело:** функция группирует инструкции; её тело — код между фигурными скобками. Примеры выполняются внутри точки входа — функции `main`.
- **Стек:** модель хранения, упоминаемая для этих локальных переменных; её устройство отложено на потом.

Для практики используйте лабораторную работу [Переменные и типы](../../../en/labs/cpp/02_variables.md). Она охватывает материал сверх записанного урока.

Урок остаётся на уровне локальных переменных, целочисленных значений, простой арифметики и вывода. Он откладывает устройство стека, получение адреса по имени, полное определение выражений, многобайтовое представление, подробности кодировки символов и механизм перегрузки. Четырёхбайтовый `int` и восьмибитный байт описывают показанное здесь окружение, а не любую возможную реализацию C++.

## Именованное хранилище

[00:00:09](https://www.youtube.com/watch?v=6ML34OuwZrc&t=9s) **Переменная** — это абстракция над хранилищем: по её имени вы работаете со значением. Задача, которая за этим стоит, в том, что программе не нужно знать фиксированный числовой адрес вроде 32. Это число принадлежит раскладке памяти, а исходный код пользуется именем.

[00:00:14](https://www.youtube.com/watch?v=6ML34OuwZrc&t=14s) В записи упоминается **стек** — модель хранения для этих локальных переменных, после чего её устройство откладывается. Это не означает, что каждая переменная в каждой программе на C++ живёт в стеке.

[00:00:17](https://www.youtube.com/watch?v=6ML34OuwZrc&t=17s) Начнём с объявления переменной. **Объявление** вводит её имя и тип; это локальное объявление является также **определением**, создающим переменную:

```cpp
int i;
```

Здесь `int` задаёт тип, `i` — имя, а точка с запятой завершает объявление. Короткие фрагменты находятся внутри `main`, точки входа программы; в полных примерах фигурные скобки ограничивают её тело. В `i` ещё осмысленно ничего не записано; не читайте её до присваивания значения. Примеры в этой заметке восстанавливают последовательные состояния из записи. Соответствующего закоммиченного файла с исходным кодом найти не удалось; ссылка на состояния в видео служит обоснованием этой реконструкции. [Транскрипт, зафиксированный в коммите](https://github.com/AntonC9018/uniCourse_dataStructuresAndAlgorithms/blob/d6b06478df12bc7fb0e14a9c58ecddcbb18c92a6/videos/cpp/05_C%2B%2B_Переменные,_присваивание,_выражения,_типы/internal/transcript.md) сохраняет повествование, а не снимок исходного кода.

[00:00:24](https://www.youtube.com/watch?v=6ML34OuwZrc&t=24s) Представьте память рядом ячеек с последовательными адресами: 32, 33, 34 и так далее. **Ячейка памяти** — это место размером в байт на этом рисунке; **адрес** задаёт её положение. Давая хранилищу имя, код может писать `i` вместо того, чтобы указывать его местоположение.

[00:00:33](https://www.youtube.com/watch?v=6ML34OuwZrc&t=33s) Смысл `int` временно отложен, чтобы идея именования могла существовать сама по себе. [00:00:39](https://www.youtube.com/watch?v=6ML34OuwZrc&t=39s) У именованной переменной всё же есть хранилище по некоторому адресу; её имя — способ программы добраться до него.

[00:00:58](https://www.youtube.com/watch?v=6ML34OuwZrc&t=58s) Не вписывайте 32 в код в смысле «моя переменная». [00:01:05](https://www.youtube.com/watch?v=6ML34OuwZrc&t=65s) Доступ идёт через имя; получение её адреса — тема последующих занятий. [00:01:22](https://www.youtube.com/watch?v=6ML34OuwZrc&t=82s) Для разбираемых здесь операций используйте объявленное имя. Утверждение записи о «единственном способе» относится к этому введению, а не запрещает более поздние возможности C++, основанные на адресах.

## Запись и копирование значений

[00:01:31](https://www.youtube.com/watch?v=6ML34OuwZrc&t=91s) Хранилище поддерживает **запись** — помещение в него значения — и **чтение** — получение хранимого значения. Добавьте **присваивание** к уже имеющемуся объявлению:

```cpp
int i;   // создаёт переменную
i = 5;   // записывает в неё 5
```

[00:01:40](https://www.youtube.com/watch?v=6ML34OuwZrc&t=100s) Держите эти действия раздельно: определение создаёт `i`, а присваивание записывает в неё. Само по себе присваивание не объявляет новую переменную. В `int i = 5;`, напротив, создание и **инициализация**, задающая первое значение, происходят вместе.

[00:01:54](https://www.youtube.com/watch?v=6ML34OuwZrc&t=114s) Чтобы перенести значение между именованными местами, сначала создайте место назначения. [00:02:01](https://www.youtube.com/watch?v=6ML34OuwZrc&t=121s) Расширим программу:

```cpp
int i;
i = 5;
int a;
a = i;
```

[00:02:08](https://www.youtube.com/watch?v=6ML34OuwZrc&t=128s) Правая часть — это **выражение**, нечто, что вычисляется и даёт значение. Его строгое определение отложено; начните с имени переменной. [00:02:13](https://www.youtube.com/watch?v=6ML34OuwZrc&t=133s) Чтение `i` справа получает число, которое там сейчас хранится.

[00:02:27](https://www.youtube.com/watch?v=6ML34OuwZrc&t=147s) **Значение** здесь — это хранимое число: более раннее присваивание записало в `i` пятёрку. [00:02:32](https://www.youtube.com/watch?v=6ML34OuwZrc&t=152s) Значит, `a = i;` читает из `i` число 5 и записывает его копию в `a`. Теперь обе содержат 5. Копируется значение, а не устанавливается постоянная связь между переменными.

<details>
<summary>После копирования изменение `i` автоматически изменит `a`?</summary>

Нет. Присваивание уже скопировало число 5. У каждой переменной своё хранимое значение.

</details>

## Вычисление арифметики до присваивания

[00:02:37](https://www.youtube.com/watch?v=6ML34OuwZrc&t=157s) Копирование полезно, но для вычислений нужны операции над значениями. Дополним предыдущее состояние: сложим два хранимых числа и запишем результат обратно в `i`:

```cpp
// До этой строки: i равно 5 и a равно 5.
i = i + a;
```

[00:02:47](https://www.youtube.com/watch?v=6ML34OuwZrc&t=167s) Знак равенства делит присваивание на место назначения слева и выражение справа. [00:02:56](https://www.youtube.com/watch?v=6ML34OuwZrc&t=176s) **Вычисление** находит значение этого выражения ещё до того, как присваивание сохранит результат. Пока вычисляется правая часть, старое значение `i` остаётся доступным.

[00:03:15](https://www.youtube.com/watch?v=6ML34OuwZrc&t=195s) Это выражение сложнее простого имени, потому что включает **оператор** — `+`. Его **операнды** — это выражения по обе стороны: `i` и `a`.

[00:03:19](https://www.youtube.com/watch?v=6ML34OuwZrc&t=199s) Скобки делают группировку явной:

```cpp
i = (i + a);
```

[00:03:32](https://www.youtube.com/watch?v=6ML34OuwZrc&t=212s) Проследите за потоком значений:

1. Вычислите каждый операнд, чтобы получить его значение.
2. [00:03:51](https://www.youtube.com/watch?v=6ML34OuwZrc&t=231s) Считайте хранимые числа, а не складывайте имена или их адреса.
3. [00:04:03](https://www.youtube.com/watch?v=6ML34OuwZrc&t=243s) Мысленно подставьте известные значения: `i + a` превращается в `5 + 5`, что даёт 10.
4. [00:04:19](https://www.youtube.com/watch?v=6ML34OuwZrc&t=259s) Запишите 10 в место назначения слева, в `i`. Значение в `a` остаётся равным 5.

Это описание смысла вычисления, а не требуемой последовательности инструкций процессора и не гарантированного порядка чтения операндов. Итоговое состояние видно также в [00:06:00](https://www.youtube.com/watch?v=6ML34OuwZrc&t=360s).

<details>
<summary>Почему `i` может стоять с обеих сторон, не теряя слишком рано своё старое значение?</summary>

Правая часть использует старое значение, чтобы вычислить результат. И только затем присваивание заменяет значение в месте назначения.

## Типы задают размер хранилища

[00:04:25](https://www.youtube.com/watch?v=6ML34OuwZrc&t=265s) Вернёмся к `int`. **Тип** определяет значения, которые может представлять переменная, и хранилище, необходимое для них. Здесь `int` представляет целые числа в четырёх байтах. **Байт** — это одна адресуемая ячейка на рисунке, поэтому одно целое число занимает четыре последовательные ячейки.

[00:04:33](https://www.youtube.com/watch?v=6ML34OuwZrc&t=273s) Как число представляется в нескольких байтах — тема отдельного видео; здесь нужен только размер хранилища. [00:04:38](https://www.youtube.com/watch?v=6ML34OuwZrc&t=278s) Замените исходный набросок «одна переменная — одна ячейка» на четыре ячейки размером в байт для каждого `int`.

[00:04:54](https://www.youtube.com/watch?v=6ML34OuwZrc&t=294s) На рисунке `i` располагается по адресам с 32 по 35. Конечный адрес 36 является **исключительным**: это граница после последнего байта. [00:05:06](https://www.youtube.com/watch?v=6ML34OuwZrc&t=306s) Вторая четырёхбайтовая переменная `a` нарисована сразу за ней:

| Переменная | Тип | Включённые адреса | Исключительный конец |
| --- | --- | --- | --- |
| `i` | `int` | 32, 33, 34, 35 | 36 |
| `a` | `int` | 36, 37, 38, 39 | 40 |

Соответствующие объявления, сохранившиеся в [записанном состоянии 00:06:00](https://www.youtube.com/watch?v=6ML34OuwZrc&t=360s), таковы:

```cpp
int i;
int a;
```

Эти адреса и соседство — иллюстрация. Две отдельные локальные переменные не обязательно оказываются рядом. Точно так же четыре байта — это размер `int` в записанном окружении; C++ допускает и другие ширины. См. [требования к целочисленным типам в черновике C++](https://eel.is/c++draft/basic.fundamental).

## Выбор одного байта

[00:05:18](https://www.youtube.com/watch?v=6ML34OuwZrc&t=318s) Теперь меняется исходное требование: зарезервировать всего один байт и хранить числа от 0 до 255. Четырёхбайтовый `int` больше, чем нужно.

[00:05:24](https://www.youtube.com/watch?v=6ML34OuwZrc&t=324s) **Уточнение к произнесённому диапазону:** знаковое 32-битное целое лежит в диапазоне от −2147483648 до 2147483647, а не примерно от минус четырёх миллиардов до плюс четырёх миллиардов. Соответствующий беззнаковый диапазон — от 0 до 4294967295. Это следует из [правил диапазонов знаковых и беззнаковых типов](https://eel.is/c++draft/basic.fundamental).

[00:05:53](https://www.youtube.com/watch?v=6ML34OuwZrc&t=353s) Подключите целочисленный **заголовочный файл**, файл с нужными объявлениями типов, затем смените тип у `i`. В [записанном состоянии 00:06:05](https://www.youtube.com/watch?v=6ML34OuwZrc&t=365s) видны `<stdint.h>` и `uint8_t`:

```cpp
#include <stdint.h>

int main()
{
    uint8_t i;
    i = 5;
    int a;
    a = i;
    i = (i + a);
}
```

Соответствующий заголовочный файл C++ — `<cstdint>`, предоставляющий `std::uint8_t`. Типы точной ширины доступны там, где они поддерживаются реализацией; см. [спецификацию целочисленных заголовочных файлов C++](https://eel.is/c++draft/cstdint.syn). Рисунок остался от прежних четырёхбайтовых переменных; после смены типа не судите о размере `i` по старому размеру прямоугольника.

[00:06:07](https://www.youtube.com/watch?v=6ML34OuwZrc&t=367s) **Беззнаковый** означает, что в диапазоне нет отрицательных чисел: все восемь бит значения дают числа от 0 до 255. Знаковое восьмибитное целое, наоборот, покрывает от −128 до 127.

[00:06:19](https://www.youtube.com/watch?v=6ML34OuwZrc&t=379s) Прочитайте имя по частям: `u` означает беззнаковый, `int` — целое число, `8` — восемь бит, а суффикс `_t` помечает имя типа. **Бит** хранит 0 или 1; восемь бит образуют один байт в этом окружении.

## Присваивание вне диапазона

[00:06:33](https://www.youtube.com/watch?v=6ML34OuwZrc&t=393s) Максимальное значение равно 255. Что произойдёт, если в присваивании попробовать 256? Запись называет это **переполнением**: пытаемое число не помещается в диапазон получателя.

[00:06:47](https://www.youtube.com/watch?v=6ML34OuwZrc&t=407s) Измените прежнее присваивание и скомпилируйте. Диагностика, видимая в [00:06:51](https://www.youtube.com/watch?v=6ML34OuwZrc&t=411s), называет это **предупреждением**, указывает, что в этой системе `uint8_t` — это `unsigned char`, и сообщает, что преобразование меняет 256 на 0:

```cpp
uint8_t i;
i = 256;  // зафиксированное предупреждение: преобразование меняет 256 на 0
```

Зафиксированная команда — `g++ main.cpp`. Хотя докладчик называет эту диагностику ошибкой, именно эта компиляция выдаёт предупреждение и продолжает работу. **Преобразование**, меняющее значение на тип получателя, сохраняет 0; в байте оно никогда не сохраняет 256. Это согласуется с [правилом целочисленных преобразований C++](https://eel.is/c++draft/conv.integral).

## Вывод выражений и преобразованных значений

[00:07:04](https://www.youtube.com/watch?v=6ML34OuwZrc&t=424s) Переменную можно использовать как выражение и при выводе. **Вывод** отправляет значение в терминал; `std::cout << expression;` вычисляет выражение и вставляет его результат в стандартный поток вывода. В [состоянии 00:07:15](https://www.youtube.com/watch?v=6ML34OuwZrc&t=435s) выражение вывода ненадолго меняется на сложение:

```cpp
// После присваивания вне диапазона i уже содержит 0.
std::cout << (i + 5);
```

Это показывает, что аргументом может быть вычисление, а не только имя. Зафиксированное состояние — незавершённая правка: в терминале всё ещё видны результаты прежнего запуска, поэтому оно не подтверждает результат вывода для этого нового выражения.

[00:07:21](https://www.youtube.com/watch?v=6ML34OuwZrc&t=441s) Затем демонстрация разделяет вывод числа и вывод символа, преобразуя значение байта в `int`. В [00:07:27](https://www.youtube.com/watch?v=6ML34OuwZrc&t=447s) видна такая программа:

```cpp
#include <iostream>
#include <stdint.h>

int main()
{
    uint8_t i;
    i = 256;
    int a = i;
    std::cout << a;
}
```

В терминале видно ещё одно предупреждение компиляции, затем запуск, печатающий `0`. **Преобразование** в `int` сохраняет значение, уже находящееся в байте, — ноль. Оно меняет способ печати этого значения; вернуть отброшенное 256 оно не может.

[00:07:28](https://www.youtube.com/watch?v=6ML34OuwZrc&t=448s) Здесь два отдельных вопроса: преобразование в байт потеряло пытаемое число, а операция вывода использует тип выражения, чтобы выбрать представление.

[00:07:34](https://www.youtube.com/watch?v=6ML34OuwZrc&t=454s) Объяснение через «прибавить единицу к максимуму» описывает оборачивание результата при записи обратно в байт. Упрощённая иллюстрация этого объяснения:

```cpp
uint8_t i;
i = 255;
i = i + 1;  // при сохранении результата в uint8_t получается 0
int a = i;
std::cout << a; // печатает число 0
```

Это учебный пример, а не ещё один зафиксированный тест. Именно преобразование при сохранении оборачивает значение; само по себе вычисление более широкого результата не означает, что этот результат уже стал нулём. См. [правило целочисленных преобразований](https://eel.is/c++draft/conv.integral).

[00:07:44](https://www.youtube.com/watch?v=6ML34OuwZrc&t=464s) Исправление — использовать перед выводом другую, более широкую переменную. Чтобы сохранить само число 256, более широкий получатель должен получить это число до того, как оно будет сужено до байта. Копирование уже обёрнутого байта в более широкую переменную сохраняет лишь ноль.

[00:07:47](https://www.youtube.com/watch?v=6ML34OuwZrc&t=467s) **Перегрузка** означает, что для одной и той же операции доступны разные поведения, и выбор задаётся типами. Её полный механизм отложен. [00:07:53](https://www.youtube.com/watch?v=6ML34OuwZrc&t=473s) В этой системе вывод `int` форматирует число, а вывод `uint8_t` — здесь псевдонима (другого имени) для `unsigned char` — вставляет символ. Это поведение описано в [спецификации вставки символов](https://eel.is/c++draft/ostream.inserters.character).

<details>
<summary>Почему копирование байта в `int` чинит числовой вывод, но не возвращает 256?</summary>

В байте уже хранится 0. Копирование сохраняет это значение в другом типе. Теперь вывод форматирует число 0, а не вставляет символ с кодом 0.

</details>

## Чтение объявления

[00:08:27](https://www.youtube.com/watch?v=6ML34OuwZrc&t=507s) **Тип** описывает значения и поведение переменной; здесь подчёркивается именно размер хранилища. В этих объявлениях он стоит перед именем. [00:08:35](https://www.youtube.com/watch?v=6ML34OuwZrc&t=515s) Сравните объявления из [записанной программы](https://www.youtube.com/watch?v=6ML34OuwZrc&t=365s):

```cpp
int a;       // четыре байта в записанном окружении
uint8_t i;   // один восьмибитный байт в этом окружении
```

[00:08:44](https://www.youtube.com/watch?v=6ML34OuwZrc&t=524s) `int` — это **целочисленный тип**: он представляет целые значения. Именно поэтому его называют «целым». [00:09:00](https://www.youtube.com/watch?v=6ML34OuwZrc&t=540s) Другие типы могут вообще не представлять числа; они выходят за рамки этого урока.

[00:09:05](https://www.youtube.com/watch?v=6ML34OuwZrc&t=545s) Запись `int` перед `a` выбирает тип, который здесь требует четырёх ячеек размером в байт. Выбор беззнакового типа в один байт для `i` даёт ей одну ячейку и меньший диапазон. Имя определяет переменную, а её тип — то, как её хранимое значение может быть представлено и использовано.
