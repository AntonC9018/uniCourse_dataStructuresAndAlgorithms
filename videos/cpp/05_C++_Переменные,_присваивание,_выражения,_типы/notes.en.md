# Variables, assignment, expressions, and types

[00:00:00](https://www.youtube.com/watch?v=6ML34OuwZrc&t=0s) This lesson builds a small program from named storage: create a variable, write a number into it, copy that number, calculate a new value, and choose a type that determines its storage and printing behaviour.

The terms you will need are:

- **Memory cell, address, and variable:** a cell is a byte-sized location in the lesson's memory drawing; its address identifies its position. A variable gives program code a name for an object that stores a value.
- **Abstraction:** a simpler way to use something without managing its underlying details. A variable name hides the details of locating storage.
- **Declaration and definition:** a declaration introduces a name and its type; the local declarations here are also definitions, creating the variables. **Initialization** supplies a value as a variable is created.
- **Value, reading, writing, and assignment:** a value is the stored number in these examples. Reading obtains it; writing replaces it. Assignment, written with `=`, writes the result on the right into an existing destination on the left.
- **Expression, evaluation, operator, and operand:** an expression produces a value when evaluated. An operator such as `+` performs an operation on its operands, the expressions it combines. Parentheses group an expression.
- **Type, alias, and integer:** a type determines permitted values, storage requirements, and supported behaviour. An alias is another name for the same type. An integer is a whole number; `int` is the integer type used first.
- **Bit, byte, and width:** a bit holds 0 or 1. Here a byte contains eight bits, and a type's width counts its value bits. **Signed** integers include negative values; **unsigned** integers start at zero. `uint8_t` is an unsigned integer type with exactly eight bits, where available.
- **Header and compiler:** a header provides declarations used by a program; `#include` makes its contents available. The compiler translates source code and issues diagnostics, including warnings and errors.
- **Conversion and overflow:** conversion changes a value to another type. The recording calls an out-of-range byte conversion “overflow”; here it wraps the stored number into the byte's range.
- **Output, character code, and overloading:** output sends data to a destination such as the terminal. `std::cout` is C++'s standard output stream and `<<` inserts a value into it. A character code is a number representing a character; ASCII is the code table used in the examples. Overloading provides different behaviours under the same operation name, selected using types.
- **Function and body:** a function groups instructions; its body is the code between braces. The examples run inside the entry function named `main`.
- **Stack:** the storage model mentioned for these local variables; its layout is deferred.
