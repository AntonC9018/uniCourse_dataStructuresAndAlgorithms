# From a grid calculation to blocks, functions, and structures

This lesson develops three ways to make a C++ program easier to change: give short-lived calculations their own blocks, give repeated work a function, and give related data a structure. The example is a distance between game objects. Follow each version before moving to the next: each improvement answers a problem exposed by the previous version.

These terms will be used throughout:

- **Grid, cell, coordinate, index, and position:** a grid is a rectangular arrangement of cells. An integer coordinate identifies a location along one axis; an index is its numbered position, starting at zero here. A position combines x and y.
- **Integer, scalar, type, and variable:** an integer is a whole number; `int` is the integer type used here. A type describes the kind of value stored. A variable is a named object holding a value; a scalar, such as an integer, holds one value rather than a group of fields.
- **Declaration, allocation, initialization, and assignment:** a declaration introduces a variable, allocation provides its storage, initialization gives its starting value, and assignment writes a new value into an existing variable.
- **Absolute value and Manhattan distance:** absolute value is magnitude without direction or sign. Adding the absolute differences on two axes gives the Manhattan distance: the minimum count of horizontal and vertical one-cell moves on an unobstructed grid.
- **Expression, evaluation, operator, and operand:** an expression describes a computation; evaluation obtains its value. An operator acts on operands, such as the two values used by subtraction. Expressions can be nested inside other expressions.
- **Header and standard library:** a header makes declarations available through `#include`. The `std::` prefix identifies names in the C++ standard library.
- **Block, scope, lifetime, local variable, and shadowing:** a block encloses statements in braces. Scope determines where a name is usable; lifetime determines when its object exists. Local variables belong to a block or function. Shadowing occurs when an inner declaration hides an outer name.
- **Stack and memory cell:** the recording models temporary local storage as a stack. A drawn cell represents storage for a value; it need not be one byte or a distinct physical machine slot.
- **Function, interface, signature, and body:** a function names an operation. Its interface describes inputs and results; its body implements the operation. “Signature” here informally refers to the function header that makes the interface readable.
- **Call, caller, callee, argument, parameter, and passing by value:** a call invokes a function. The caller supplies argument expressions; the callee receives their values in parameter variables. Passing by value initializes separate parameters with copies.
- **Return type, return value, and return statement:** the return type describes the kind of result; the return value is a particular call's result. A return statement evaluates an expression and finishes the call with that result.
- **Procedure, void, console, and side effect:** the lesson calls a function with no returned value a procedure; its return type is `void`. A console displays text. Printing there is a side effect, an observable action distinct from supplying a return value.
- **Structure, field, and dot access:** a structure defines a type that groups related values. A field is a named part of that value; dot access selects it, as in `player.x`.
- **Braced and designated initialization:** braces can supply starting field values in declaration order. Designated initialization labels them explicitly, for example `.x = 1`.
- **String, string literal, and string view:** a string represents text. A quoted string literal writes text directly into the program. `std::string` owns text; `std::string_view` refers to existing text without owning it.
- **Unit and temporary value:** the lesson's `Unit` structure combines a position and a display name. A temporary value can be built directly inside an expression without a separate named variable.

[00:02:56](https://www.youtube.com/watch?v=6JtlzvwhHr0&t=176s) A step upward cannot cancel a horizontal step merely because its coordinate difference is negative. [00:03:07](https://www.youtube.com/watch?v=6JtlzvwhHr0&t=187s) Use **absolute value**, the magnitude after discarding the sign, on each difference:

```text

         = 2 + 1
         = 3
```
